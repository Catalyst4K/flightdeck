# Flightdeck

A personal fleet-management, dispatch, live-tracking and logbook companion for
Microsoft Flight Simulator — fleet → SimBrief dispatch → SimConnect tracking on a map →
logbook with landing analysis. Local-first, no accounts, no server.

Modelled loosely on [SimToolkitPro](https://simtoolkitpro.co.uk/); see `PLAN.md` for
why this exists as its own project rather than just using that.

**Status:** pre-kickoff. See `PLAN.md` for the full plan and `docs/decisions.md` for
open decisions still to be made.

## Getting started

Not scaffolded yet. Open this repo in Claude Code — it reads `CLAUDE.md` and `PLAN.md`
automatically and knows what to do first.
